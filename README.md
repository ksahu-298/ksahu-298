# ⭐ Featured GenAI / RAG Projects

### 🗂️ HR Policy Assistant (RAG Chatbot)

**LangChain • Groq • Jina Embeddings • FAISS • LangSmith • Streamlit**

A RAG chatbot that answers employee questions from a company's HR policy document, grounding every answer in retrieved policy text — with a dedicated safety layer screening questions and answers for prompt injection, PII leaks and unauthorized promises.

**Highlights:**

* Chunked and embedded the policy document, indexed in FAISS for fast local retrieval
* Built a LangChain agent (Groq-hosted `gpt-oss-20b`) with a custom policy-search tool
* Added a second safety model (`gpt-oss-safeguard-20b`) to screen inputs and outputs
* Full observability with LangSmith tracing and deployed on Streamlit Community Cloud

🔗 **[Live Demo](https://hr-rag-assist.streamlit.app/)** • 🔗 **[View Code](https://github.com/ksahu-298/Gen_AI-Projects/tree/main/02_HR_Policy_RAG_Assistant)**

### 📄 Company Docs AI Chatbot (End-to-End RAG)

**LangChain • NVIDIA Embeddings • Pinecone • Groq • Streamlit**

An AI chatbot that answers questions from company PDFs — HR policy, IT security, product guide — and **cites the exact source file and page** for every fact. Replies "I don't know" when the answer isn't in the documents, instead of guessing.

**Highlights:**

* Loaded and chunked PDFs with LangChain using overlapping chunks for better retrieval
* Embedded chunks with NVIDIA AI Endpoints (`nvidia/nemotron-3-embed-1b`) and indexed them in serverless Pinecone
* Generated grounded, source-cited answers with a Groq-hosted LLM (`qwen/qwen3.8-27b`)
* Built entirely on free-tier services, deployed on Streamlit Community Cloud

🔗 **[Live Demo](https://rag-knowledge-assist.streamlit.app/)** • 🔗 **[View Code](https://github.com/ksahu-298/Gen_AI-Projects/tree/545f2351dc6d054779ce7e63a19709513a768ad0/03_RAG_Knowledge_Assistant)**
